# Dwarika Rebuild

Modern Next.js website for a futuristic virtual nation where humans and AI co-govern democracy and economy.

## Stack

- Next.js + React
- Tailwind CSS
- CSS-based micro animations (build-safe, no runtime motion dependency)

## Run locally

```bash
npm install
npm run dev
```

## Pages

- `/` Home
- `/government`
- `/economy`
- `/citizenship`
- `/roadmap`
